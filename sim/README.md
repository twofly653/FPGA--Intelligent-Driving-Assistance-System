# 仿真、离线验证与回归

本目录含既有时钟、测距复位、运动目标关联与视频回放测试。历史 JSON、图像、版本号、绝对路径和哈希作为原始证据保留，不代表最终 R22 重新完成了全部测试。

固件 C 源码已移动到 `../src/firmware/src/`，主应用构建入口移动到 `../build/`。Host 预览与 C 测试需要本机 GCC；视频回放还需另备被忽略的原始视频与 RGB565 输入。缺少这些依赖的历史实验脚本不能直接复现。

参考源码中未接入当前工程的 ODMD、qd-3dt 下载副本已清理；研究思路记录与测试证据保留。它们不构成本项目已部署的神经网络算法。
