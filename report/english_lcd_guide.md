# DriveSense 全英文扩展屏使用说明

适用候选版本：`CAMERA_SYNC_R10LCD_EN_20261028`。界面按 240 × 280 屏幕重新排版，采用深色背景、青色强调、统一字体和方块触控入口。屏幕上的标题、数值单位、按钮和状态提示均为英文。

**验证状态：当前说明未记录烧录结果。候选文件、离线预览与测试不代表已经在板卡上验收；实际下载及检查结果由主任务另行更新。**

## 首页

中央 `LOCAL TIME` 是真实的 24 小时时钟，以 `HH:MM:SS` 显示；下方为英文星期及 `YYYY.MM.DD` 日期，时区标记为 `UTC+8`。这部分与行程计时独立。

首次开机尚未收到电脑时间时，显示 `--:--:--` 和 `WAITING FOR PC SYNC`，不会把开机时长当成真实时间。运行本候选目录的网页桥接程序并连接板卡后，程序会在收到有效实时遥测后发送电脑的 UTC+8 时间，并每 60 秒校正一次。拍照忙碌时会暂缓对时。

同步后即使网页串口断开，板卡仍使用 XTime 单调计时继续走时。此方案没有电池后备实时时钟；主板断电或 CPU 重启后需再次连接候选网页服务同步。仅返回首页或重启 UI 不会清除已同步时间。电脑系统时间应正确。

左下 `TRIP TIMER` 是原有行程计时，状态为 `READY`、`RUNNING` 或 `PAUSED`。五向开关仅在首页改变计时状态：

| 操作 | 功能 |
| --- | --- |
| 向左（L） | 清零并回到 READY |
| 向右（R） | 从 READY 开始计时 |
| 向上（U） | 运行时暂停 |
| 向下（D） | 仅在暂停时继续 |
| 中心按下 | 打开功能菜单 |
| 轻触右下 MENU | 打开功能菜单 |

进入其他页面不会停止已经运行的计时；其他页面上的方向操作不会修改计时。原有主板 BTN1、BTN2、BTN3 仍属于摄像头图像模式控制。

## 功能菜单

轻触方块打开页面；右上 `PAGE` 切换菜单页，左上 `BACK` 返回。完整构建包含以下九个功能入口：

| 菜单名称 | 页面内容及操作 |
| --- | --- |
| Cabin | 温度 `deg C`、相对湿度 `% RH`、气压 `hPa` |
| Heading | 与网页同源的相对航向；`INFO` 打开方向说明 |
| Light | 光照 `lx`；右上 `RGB / LUX VIEW` 切换照度与原始光通道 |
| Attitude | 人工地平线、Roll/Pitch、相对 Yaw；需要重新初始化时轻触 `ALIGN` 并保持板子静止 |
| Raw IMU | 加速度及陀螺仪六轴读数 |
| Sound | 近似声级 `approx dB`、`ALERT` 开关及每次 5 dB 的阈值调节 |
| Ambient | `RAINBOW` 氛围灯启停；一轮结束自动停止，距离告警具有优先级 |
| Distance | 前方单点 ToF 距离、分级状态及距离条；单位为毫米 |
| Objects | 页面标题为 `Motion`；`ENABLE / DISABLE` 开关、运动区域数量及分析状态，与网页识别开关同步 |

菜单顺序为：第一页 Cabin、Heading、Light、Attitude；第二页 Raw IMU、Sound、Ambient、Distance；第三页 Objects。该列表对应 README 中启用 ToF、运动目标与网页同步的完整构建命令。

`Objects` 延续固定摄像头下的运动区域检测。静止背景建立期间显示 `Learning background`，全局变化时提示 `Keep camera still`；它不提供物体类别识别，也不把单点 ToF 距离分别分配给每个绿框。

## 正确理解显示状态

- **相对航向**：Heading 的零点来自姿态初始化参考，界面明确提示 `Relative yaw / not magnetic north`。它用于展示转动和与网页同步，不能按磁北指南针验收，随时间可能漂移。
- **姿态**：未初始化、IMU 离线或数据过期时显示 `--` 及原因。若底层未来提供有效磁航向，Attitude 才会显示 `HEADING / Magnetic heading active`；当前通常为 `YAW REL`。
- **传感器数据**：温湿度、气压、光照或 IMU 无新鲜有效数据时显示 `--`、`Waiting for sensor data` 或 `Sensor unavailable`，不把零值当作正常测量。
- **距离**：离线或无有效测距时显示 `--`、`Sensor offline / Range unavailable` 及未知状态。页面标有 `Demo thresholds / single-point ToF`，是当前演示阈值和单点测距的实际能力。
- **目标检测**：关闭时显示 `Detection off / Analysis paused`；无可用帧或结果过期时显示 `Waiting for video`、数量 `--`。有效结果为零时才显示数量 `0`。

## 建议检查顺序

1. 确认扩展屏与 HDMI 都正常；检查首页时钟在连接候选网页桥后由等待变为真实时间。
2. 首页分别测试左、右、上、下和 MENU，确认时钟与行程计时互不影响。
3. 逐页查看数值、单位、返回与翻页；无数据时应显示等待或无效状态。
4. 保持镜头固定，在 Objects 开关识别，核对网页状态和 HDMI 绿框联动。
5. 再检查 BTN1 边缘、BTN2 灰度、BTN3 去雾及拍照等原有摄像头功能；本轮界面预览不能代替这些板上验证。
